# Git в VS Code: что удобно, а что — нет

## 3 вещи, которые удобны в VS Code

1. **Визуальный diff изменений.**
   В панели Source Control сразу видно, какие файлы изменены.
   Клик по файлу открывает side-by-side diff.

2. **Быстрые commit / push / pull через UI.**
   Вводишь сообщение коммита, нажимаешь галочку — коммит готов.

3. **Встроенный редактор merge-конфликтов.**
   VS Code подсвечивает блоки `<<<<<<<`, `=======`, `>>>>>>>`
   и предлагает кнопки «Accept Current», «Accept Incoming», «Accept Both».

## 1 вещь, которую удобнее делать в терминале

**Interactive rebase (`git rebase -i`).**
Объединение коммитов (squash), переупорядочивание, редактирование сообщений —
всё это делается через текстовый редактор, который открывает Git.
В терминале это прозрачнее и предсказуемее, чем в UI.
